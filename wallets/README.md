# Wallets

Kryptokrona wallets let you hold, send and receive **XKR**, and — with **Aesir** — swap directly between **Bitcoin and XKR** without a custodian or an exchange.

* [**Aesir**](aesir/README.md) — the official cross-platform desktop wallet (Windows, macOS, Linux), with built‑in trustless **BTC ⇄ XKR atomic swaps**.
  * [Atomic Swaps (BTC ⇄ XKR)](aesir/swaps.md) — what they are, why they're useful, and how to use both the taker and maker side.

> Looking for the older desktop wallet or paper‑wallet guides? See **Guides → Wallets**.
