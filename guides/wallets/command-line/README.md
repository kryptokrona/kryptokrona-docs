# 👾 Command Line

{% tabs %}
{% tab title="Terminal/CLI" %}

A high performance api that can handle multiple wallets.

[**kryptokrona-service**](../../../kryptokrona/api/legacy-wallet-rpc-api.md)

{% endtab %}
